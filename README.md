# أكاديمية التحول الرقمي

واجهة عربية متجاوبة مع كتالوج من 300 دورة: 100 مجانية، 100 بالجنيه المصري، و100 بالدولار.

## التشغيل

يتطلب Python فقط:

```powershell
py server.py
```

ثم افتح `http://localhost:8000`. نقاط الباك-إند: `http://localhost:8000/api/health` و`http://localhost:8000/api/courses`.

تفتح بطاقات الدورات صفحة الدورات الرسمية في [مهارة-تك](https://maharatech.gov.eg/course/). لا تُنسخ أو تُضمّن فيديوهات المنصة، حفاظًا على حقوق المحتوى وشروط الوصول الخاصة بها.
